## Review Artifact Standard

Each feature folder contains the independent, multi-lens review reports generated by the Goldfish reviewers:
1. **Skeptical Architect (`egm-zoom-out`)**: High-altitude simplicity, YAGNI, and dependency minimization.
2. **Naive Reader (`egm-comprehension`)**: Zero-assumed-knowledge clarity, failure modes, and developer ergonomics.
3. **Hostile Design Critic (`egm-design`)**: Security, concurrency, denial-of-service hazards, and failure modes.
4. **Pragmatic Tech Lead (`egm-implementation-readiness`)**: Actionable schemas, protocols, and migration boundaries.
5. **Technical Quality Auditor (`egm-codebase-details`)**: Codebase drift, existing subsystem reuse, and SRE observability.
6. **Inventive Catalyst (`egm-inventive-catalyst`)**: TRIZ contradiction resolution and inventive transforms.
7. **Synthesis Report**: Deduplicated architectural consensus, definitive decisions, and implementation blueprint.
